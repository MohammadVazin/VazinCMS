# ارتقا و بازگشت نسخهٔ VazinCMS

## ارتقا

1. سازگاری نسخهٔ فعلی را در `vazin-package.json` بررسی کنید.
2. از runtime و پایگاه‌داده backup مستقل بگیرید و restore آن را در محیط ایزوله امتحان کنید.
3. checksum و امضای بستهٔ مقصد را تأیید کنید.
4. installer رسمی را اجرا و health check و مسیرهای اصلی مدیر را بررسی کنید.

## بازگشت نسخه

`deploy/rollback.sh` فقط کد را به نسخهٔ قبلی بازمی‌گرداند؛ داده، schema و runtime را حذف نمی‌کند. اگر migration ناسازگار انجام شده باشد، قبل از rollback برنامهٔ بازیابی دیتابیس لازم است.

## شرط توقف

در صورت خطای health، خطای migration، ناسازگاری manifest یا شکست آزمون بازگردانی، انتشار را متوقف کنید و از پشتیبانی رسمی در <https://cms.vazin.online> کمک بگیرید.
