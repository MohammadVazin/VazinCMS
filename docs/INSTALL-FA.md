# نصب VazinCMS

## پیش‌نیازها

- PHP 8.2 یا بالاتر
- وب‌سرور و پایگاه‌دادهٔ پشتیبانی‌شده
- یک دامنه با HTTPS فعال

## مراحل نصب

1. نسخهٔ رسمی را فقط از <https://cms.vazin.online> یا GitHub رسمی دریافت کنید.
2. checksum و امضای انتشار را قبل از اجرا بررسی کنید.
3. کد را در مسیر جدا از runtime قرار دهید و `.env.example` را به `.env` تبدیل کنید.
4. مقادیر محیطی، اتصال دیتابیس و `APP_KEY` را فقط در `.env` وارد کنید.
5. installer رسمی `deploy/install.sh` را اجرا کنید.
6. حساب مدیر اول را از مسیر نصب بسازید و سپس ورود و health check را بررسی کنید.

## ممنوع

فایل `.env`، کلیدها، tokenها، خروجی دیتابیس یا پوشهٔ uploads را در Git، تیکت عمومی یا کانال عمومی منتشر نکنید.

پشتیبانی رسمی: <https://cms.vazin.online>
