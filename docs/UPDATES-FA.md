# به‌روزرسانی‌های رسمی VazinCMS

هسته فقط فید پایدار `https://cms.vazin.online/releases/stable.json` را می‌خواند. همهٔ نشانی‌های فایل باید HTTPS و روی `cms.vazin.online` باشند؛ فید با ساختار نامعتبر یا نشانی غیررسمی رد می‌شود.

پنل مدیریت فقط وجود نسخهٔ جدید را اعلام می‌کند. دانلود، اعتبارسنجی SHA-256 و امضای انتشار، snapshot و اجرای مسیر ارتقای rollback‌دار همچنان مسئولیت فرایند انتشار است؛ CMS هرگز کد جدید را از راه دور دانلود یا اجرا نمی‌کند.

بررسی پس‌زمینه‌ای حداکثر هر شش ساعت cache می‌شود و مدیر می‌تواند از صفحهٔ «قالب‌ها و ماژول‌ها» آن را دستی تازه‌سازی کند.
