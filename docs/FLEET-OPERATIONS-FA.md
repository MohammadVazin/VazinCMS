# عملیات ناوگان VazinCMS

`deploy/fleet-audit.sh` دروازهٔ فقط‌خواندنی انتشار است. این ابزار هر شش نصب رسمی را با نسخهٔ مورد انتظار مقایسه می‌کند: سلامت HTTPS، پاسخ دقیق `/health`، فایل `VERSION` و `MANIFEST.sha256` باید هم‌زمان معتبر باشند.

```bash
sudo /opt/VazinCMS-10.28.0/deploy/fleet-audit.sh 10.29.0
```

کد خروج `0` تنها زمانی است که همهٔ نصب‌ها سالم و دقیقاً هم‌نسخه باشند. خروج `70` یعنی انتشار یا ارتقای بعدی باید متوقف شود تا نصب ناسالم اصلاح یا rollback شود.

این ابزار هیچ فایل، داده، تنظیم یا نسخه‌ای را تغییر نمی‌دهد و هیچ secretای نمی‌خواند. اجرای ارتقای واقعی تنها پس از انتشار نسخهٔ امضاشده، CI سبز، تهیهٔ backup و عبور از این دروازه انجام می‌شود.
