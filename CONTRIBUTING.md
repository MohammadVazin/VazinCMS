# Contributing to VazinCMS

Thank you for contributing. Please open an issue before substantial work, keep changes focused, add or update tests, and avoid committing secrets or production data.

Before submitting code:

1. Run the relevant test suite.
2. Verify installation and upgrade behavior when touching deployment code.
3. Preserve backward compatibility unless the issue explicitly documents a breaking change.
4. Use the Vazin UI standard for any changed user-facing interface.

By submitting a contribution, you agree that it may be distributed under the repository license.
