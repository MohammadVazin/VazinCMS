# VazinCMS support

Official documentation and support: <https://cms.vazin.online>

For bugs and feature requests, use GitHub Issues after searching existing issues. Do not post secrets, credentials, personal data, production logs, database exports or private customer information.

For security vulnerabilities, do not use a public issue. Follow [SECURITY.md](SECURITY.md).

Commercial hosting, managed installation and integration services are separate from the free AGPL software and are coordinated through the official CMS site.
