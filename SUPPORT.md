# VazinCMS Support

VazinCMS is an open-source project maintained by Vazin Online.

## Community support

For reproducible bugs and feature discussions, use the public issue tracker of the official VazinCMS repository.

Before reporting a bug:

1. Verify that you are using a supported VazinCMS release.
2. Run the documented release and health checks.
3. Remove credentials, tokens, personal information, database contents and private infrastructure details from logs.
4. Include the VazinCMS version, PHP version, database engine and reproduction steps.

## Security issues

Do not report security vulnerabilities through a public issue.

Follow the private disclosure process documented in `SECURITY.md`.

## Commercial services

Commercial hosting, managed deployments, migration, white-label services and other Vazin Online services are separate from the open-source license and community support process.

The Vazin and VazinCMS names and logos remain subject to `TRADEMARKS.md`.
