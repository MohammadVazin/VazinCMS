# Security policy

## Reporting a vulnerability

Do not disclose vulnerabilities in public issues. Use the official VazinCMS support channel at https://cms.vazin.online and include a reproduction path, affected version, impact, and safe contact method.

Do not include passwords, API keys, tokens, personal data, or production database exports in a report.

## Supported version

The current supported stable release is 10.28.0. Security fixes are published through the official release channel and announced to managed installations.
