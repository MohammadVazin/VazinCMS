# Security policy

## Reporting a vulnerability

Do not disclose vulnerabilities in public issues. Use the official VazinCMS support channel at <https://cms.vazin.online> and include a clear reproduction path, affected version, impact, and safe contact method.

Do not include passwords, API keys, tokens, personal data, or production database exports in a report.

## Supported version

The current supported stable release is 10.30.0. Security fixes are published through the official release channel and announced to managed installations. Verify the release manifest before upgrading.

## Scope and response

Supported security reports include the VazinCMS core, official modules and official release tooling. Do not test against `cms.vazin.online` or another Vazin-managed installation without written authorization. A report is not permission to access data, disrupt service, or run a proof of concept against production.

The maintainers will acknowledge a report through the official support channel, validate impact, coordinate a fix, and publish a release note when disclosure is safe. Please allow reasonable time for remediation before public disclosure.
